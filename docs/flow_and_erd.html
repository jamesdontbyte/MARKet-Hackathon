The Demo-Critical Hyperlocal Loop

How geofencing, interest matching, local notifications, voucher generation, QR scanning, and analytics interconnect.

sequenceDiagram
    autonumber
    actor Shopper as Shopper App
    participant Geo as GeofenceService
    participant Notif as Local Notifications
    participant Supa as Supabase DB
    actor Merchant as Merchant App

    Note over Shopper,Geo: Background Position Stream Active (Foreground Service)
    Shopper->>Geo: Cross into San Jose zone OR Long-Press Simulate Enter
    Geo->>Supa: Query active promos from verified businesses matching shopper interests
    Supa-->>Geo: Returns top promo (e.g., Kape Tahanan BOGO)
    Geo->>Supa: INSERT INTO geofence_events (event_type: 'ping_sent')
    Geo->>Notif: showPromo("Promos near you in San Jose", "Buy 1 Take 1 Afternoon Coffee Hour (+2 more)")
    
    Note over Shopper,Notif: User receives notification (even screen locked)
    Shopper->>Notif: Tap notification
    Notif->>Shopper: Open PromoDetailScreen with promo payload
    Shopper->>Supa: INSERT INTO geofence_events (event_type: 'opened')
    
    Shopper->>Shopper: Tap "Save to Stash"
    Shopper->>Supa: INSERT INTO stash (user_id, promo_id)
    
    Shopper->>Shopper: Tap "Get Voucher" (First Open)
    Shopper->>Supa: INSERT INTO redemptions (status: 'issued', code: 'KT8924B1')
    Shopper->>Supa: INSERT INTO geofence_events (event_type: 'claimed')
    Shopper->>Shopper: Display scannable QR Voucher (8-char code)
    
    Note over Shopper,Merchant: Shopper presents QR voucher at counter
    Merchant->>Merchant: Open Scan Screen (camera scans QR or manual code)
    Merchant->>Supa: SELECT rpc('redeem_voucher', params: {'p_code': 'KT8924B1'})
    Note over Supa: Atomic PL/pgSQL function:
1. Verifies business ownership
2. Checks active date & limit
3. Sets redemptions.status='redeemed'
4. Increments promos.redeemed_count
5. Inserts geofence_events('redeemed')
    Supa-->>Merchant: Returns status 'ok' (or error code)
    Merchant-->>Shopper: Coffee discount honored!
    
    Merchant->>Merchant: Open Analytics Screen
    Merchant->>Supa: Aggregates geofence_events (7-day funnel reflects +1 ping, open, claim, redemption)

Supabase Database Entity Relationship Diagram (ERD)

Normalized relational schema supporting RLS security policies and storage documents.

erDiagram
    PROFILES ||--o| BUSINESSES : "owns (0..1)"
    PROFILES ||--o{ STASH : "saves (0..N)"
    PROFILES ||--o{ REDEMPTIONS : "claims (0..N)"
    PROFILES ||--o{ GEOFENCE_EVENTS : "triggers (0..N)"

    BUSINESSES ||--o{ PRODUCTS : "offers (1..N)"
    BUSINESSES ||--o{ PROMOS : "publishes (0..N)"
    BUSINESSES ||--o{ GEOFENCE_EVENTS : "attributes (0..N)"

    PROMOS ||--o{ STASH : "saved_in (0..N)"
    PROMOS ||--o{ REDEMPTIONS : "redeemed_as (0..N)"
    PROMOS ||--o{ GEOFENCE_EVENTS : "subject_of (0..N)"

    PROFILES {
        uuid id PK "references auth.users(id)"
        text role "check: shopper, merchant"
        text full_name
        text phone
        text_array interests "e.g. food, cafe, retail"
        jsonb prefs "flash_promos, expiry_reminders"
        timestamptz created_at
    }

    BUSINESSES {
        uuid id PK
        uuid owner_id FK "references profiles(id)"
        text name "e.g. Kape Tahanan"
        text category "food, cafe, salon, retail, etc."
        text subtitle
        text bio
        text address
        text phone
        text hours
        text cover_url
        float lat "e.g. 10.754707"
        float lng "e.g. 121.934428"
        float radius_m "default 1500"
        numeric rating "default 4.5"
        boolean verified "default false, auto-verified"
        timestamptz created_at
    }

    PRODUCTS {
        uuid id PK
        uuid business_id FK "references businesses(id)"
        text name
        numeric price "in Philippine Peso (PHP)"
        text category
        text description
        timestamptz created_at
    }

    PROMOS {
        uuid id PK
        uuid business_id FK "references businesses(id)"
        text title
        text description
        text promo_type "bogo, percent, amount_off"
        text value_label "e.g. BOGO, 20% OFF, P100 OFF"
        timestamptz starts_at
        timestamptz ends_at
        int redeem_limit "default 100"
        int redeemed_count "default 0"
        boolean active "default true"
        timestamptz created_at
    }

    STASH {
        uuid id PK
        uuid user_id FK "references profiles(id)"
        uuid promo_id FK "references promos(id)"
        timestamptz saved_at
    }

    REDEMPTIONS {
        uuid id PK
        uuid promo_id FK "references promos(id)"
        uuid user_id FK "references profiles(id)"
        text code "8-char uppercase unique"
        text status "issued, redeemed"
        timestamptz created_at
        timestamptz redeemed_at
    }

    GEOFENCE_EVENTS {
        bigserial id PK
        uuid user_id FK "references profiles(id)"
        uuid business_id FK "references businesses(id)"
        uuid promo_id FK "references promos(id)"
        text event_type "ping_sent, opened, viewed, claimed, redeemed"
        timestamptz created_at
    }
profiles RLS: Own row
  • iduuid (auth.users)
  • roleshopper | merchant
  • intereststext[]
  • prefsjsonb
businesses RLS: Read verified or own / Owner edit
  • id, owner_iduuid
  • name, categorytext
  • cover_urltext (nullable)
  • lat, lng, radius_mfloat
  • verifiedboolean (default false)
promos RLS: Read visible / Owner write
  • id, business_iduuid
  • title, value_labeltext
  • promo_typebogo | percent | amount
  • redeemed_count / limitint
redemptions RLS: Shopper issue / RPC redeem
  • id, promo_id, user_iduuid
  • codetext (8-char UNIQUE)
  • statusissued | redeemed
  • redeemed_attimestamptz
geofence_events RLS: Analytics Funnel
  • idbigserial
  • user_id, business_id, promo_iduuid
  • event_typeping_sent | opened | etc
  • created_attimestamptz
merchant-docs Storage (Read, upload & upsert)
  • bucketprivate
  • path patternmerchant-docs/{uid}/*
  • policyown folder insert/select/update
